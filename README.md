# Nazih Talbi — portfolio website

Static site (plain HTML, CSS and JavaScript, no build step), in English, French, Arabic and German.

## The folder

| | |
| --- | --- |
| `Open website.bat` | Opens the site on this computer (videos and YouTube films need this; double-clicking `index.html` is not enough) |
| `Update website.bat` | After adding photos or videos: rebuilds both sections (`Update photos.bat` / `Update videos.bat` do one each) |
| `Photography - put your photos here/` | Your best photos, one folder per category. See `HOW TO USE.txt` inside |
| `Videos - put your videos here/` | New reels (`Reels/<client>/`) and films (`Films/`). See `HOW TO USE.txt` inside |
| `More options/` | Automatic photo updates (watch the folder, start with Windows) |
| `_Originals (not on the website)/` | Your source videos, photos, logos, the old site. Never uploaded |
| `index.html`, `assets/` | **The website itself.** This is what is published |
| `tools/` | The scripts behind the buttons |

## Adding new work

1. **Photos:** copy them into a category folder in `Photography - put your photos here`.
2. **Reels:** copy the exported MP4 into `Videos - put your videos here/Reels/<client>`. The file name is the title.
   Optional: a `.txt` with the same name for the French/Arabic/German titles and the preview start.
3. **Films:** copy into `Videos - put your videos here/Films` (for long films, add `youtube: <link>` in the `.txt`).
4. Double-click `Update website.bat`, check with `Open website.bat`, then publish (see below).

The tools edit and sign photos, make web versions, 5-second hover previews and covers, and keep everything small
enough for GitHub. Your original files are never changed.

## Publishing

Only `index.html`, `assets/` (and the small `tools/` and buttons) go online; `.gitignore` keeps the originals out.
GitHub Pages limits: 100 MB per file, about 1 GB per site. Videos are encoded to stay well inside both.

## Where things are

| File | What it contains |
| --- | --- |
| `assets/js/i18n.js` | All interface text in the four languages |
| `assets/js/data.js` | Films, reels, clients, featured reel (titles in 4 languages), contact-form key |
| `assets/js/photos-data.js`, `videos-data.js` | Generated by the update buttons, do not edit by hand |
| `assets/js/app.js` | Intro, films, players, gallery, lightbox, contact form |
| `assets/css/style.css` | Design: colours, type, layout, mobile, right-to-left |
| `assets/media/` | Web versions of videos, photos, logos and site images |

- **Contact form:** messages go to your email through Web3Forms (key in `data.js`). When the site is online, add its
  address in the Web3Forms dashboard.
- **Hidden film:** the Algerian Investment Promotion Agency film is in `_Originals (not on the website)/Hidden website videos`.
  To show it: move its files back to `assets/media/video/` and remove `hidden: true,` from its entry in `data.js`.
